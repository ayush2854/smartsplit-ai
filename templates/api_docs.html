REST API Documentation — v1.0

All endpoints return JSON. Protected endpoints require a Bearer token in the Authorization header.

🌐 Base URL: https://smartsplit-ai.onrender.com   |   Authentication: Bearer Token (JWT)
Authentication
POST /api/auth/register Create a new account ▼
Request Body
{ "name": "Ayush Chavan", "email": "ayush@example.com", "password": "yourpassword" }
Response (201)
{ "success": true, "token": "eyJhbGci...", "user": { "id": 1, "name": "Ayush Chavan", "email": "ayush@example.com" } }
POST /api/auth/login Login and receive JWT token ▼
Request Body
{ "email": "ayush@example.com", "password": "yourpassword" }
Response (200)
{ "success": true, "token": "eyJhbGci...", "message": "Login successful" }
Groups
GET /api/groups Get all groups for logged-in user 🔒 Auth Required ▼
Headers
Authorization: Bearer <your_token>
Response (200)
{ "success": true, "groups": [ { "id": 1, "name": "Goa Trip", "members": "Raj, Priya, Arun", "created_at": "2026-08-29 11:00:00" } ] }
POST /api/groups Create a new group 🔒 Auth Required ▼
Request Body
{ "name": "Goa Trip", "members": "Raj, Priya, Arun" }
Response (201)
{ "success": true, "message": "Group created successfully", "group": { "id": 1, "name": "Goa Trip", "members": "Raj, Priya, Arun" } }
GET /api/groups/<id> Get group details with expenses and settlements 🔒 Auth Required ▼
Response (200)
{ "success": true, "group": { ... }, "expenses": [ ... ], "settlements": [ ... ], "summary": { "total_amount": 3600.0, "total_expenses": 2, "category_totals": { "Food": 600, "Accommodation": 3000 } } }
Expenses
POST /api/groups/<id>/expenses Add expense — AI auto-categorizes 🔒 Auth Required ▼
Request Body
{ "description": "Hotel booking", "amount": 3000, "paid_by": "Raj" }
Response (201)
{ "success": true, "expense": { "id": 1, "description": "Hotel booking", "amount": 3000.0, "paid_by": "Raj", "category": "Accommodation" } }
PUT /api/expenses/<id> Edit an expense 🔒 Auth Required ▼
Request Body (all fields optional)
{ "description": "Updated description", "amount": 2500, "paid_by": "Priya" }
DELETE /api/expenses/<id> Delete an expense 🔒 Auth Required ▼
Response (200)
{ "success": true, "message": "Expense deleted successfully" }
Insights & Settlements
GET /api/groups/<id>/insights Get AI-generated spending insights 🔒 Auth Required ▼
Response (200)
{ "success": true, "insight": "Your group spent Rs.3600 on this trip..." }
GET /api/groups/<id>/settlements Get settlement breakdown 🔒 Auth Required ▼
Response (200)
{ "success": true, "settlements": [ { "from": "Priya", "to": "Raj", "amount": 600.0 } ], "summary": { "total_amount": 3600.0, "per_person_share": 1200.0 } }
